## DataLake Processor (P2S) — Nov 2019 - Sep 2020
This is a big data project that processes huge amounts of data in
TeraBytes using Apache Spark and Azure Cloud. This application process
given data (csv, parquet) and process them on chunks using ApacheSpark
and generate the final parquet files with partitions and use them to create
Snowflake tables, so this data will be used by our BI dashboard tools to
display the stats I was part of backend Team and built the P2S (Publish to
Snowfale) module We used Java, SpringBoot, JPA, Apache Spark,
Snowflake, DataBricks, Apache Kafka

### Technologies
Java8, Apache Spark, Azure, Azure Databricks, Spring Boot, Spring,
Hadoop, PostgresSQL, SnowFlake, GitLab
